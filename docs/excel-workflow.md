# Excel 股息跟踪流程

本文命令从项目根目录运行；工作簿、缓存与导出图片仅保存在本机。

## 使用

编辑 `data/daily-dy.xlsx` 中的股票，然后在本目录执行：

```powershell
.\run.cmd
```

在 WSL（Linux）终端中执行：

```bash
./run.sh
```

`run.sh` 通过 WSL 的 Windows 互操作调用同目录的 `run.cmd`，复用现有的 Windows `.conda` 环境和 Node 运行时；可从任意目录启动，无需在 WSL 中重复安装 Python 依赖。需要启用 WSL Windows 互操作；此启动器不支持没有 Windows 环境的独立 Linux。

启动器使用本项目的 conda Python，无需手动激活。结果保存到 `pictures/YYYYMMDD/`。

J列“26初价格”按表头年份取当年首个交易日的不复权收盘价（2026年为1月5日）。每次更新自动补齐缺失或无效值，已有有效值保留；先复用通过校验且未超过全量复查周期的历史行情，缺少该日行情时按股票代码在线查询。首个交易日由交易日历核实；该股票当天无行情时留空并说明，避免误用后来上市或复牌的价格。年份取自J列表头；切换基准年份时应同步改J/K表头并清空需要重新获取的J值。K列为公式`当前价格÷年初价格－1`，自动跟随价格变化，表示不含现金分红的价格涨跌幅。

“股票数据”E列为最新已披露完整年度的每股现金股息，G列“最新股息率”=E列/D列当前价格。N列标明股息所属年度；F列为实施确认（1=该年度各期已实施，0=含已公告未实施或数据待核实）。只有中报不会切换完整年度；下一年度全年方案正式披露后自动滚动，不再固定任何年份。年度合计按各分红所属报告期归集，避免将跨年支付误算为跨年分红。接口失败时保留旧金额，但将所属年度及相关收益率标记为待核实；不再应用没有年度和报告期约束的手工补录。港股对应A股的年度分红同步更新。

M列为最新滚动年度股息率：按最新已公告或已实施的分红所属报告期，汇总向前一年内（不含上年同一报告期）的税前每股现金分红，再除以D列当前价格。季度分红也纳入；缺失或过旧的数据标记为待核实。按报告期计算，不按到账日期计算，也不是未来派息承诺。

O列“股息率百分位（近5年）”比较G列当前最新年度股息率与该股票过去5年逐日股息率。历史每个交易日按当时已披露的最新完整年度每股现金股息÷当天不复权收盘价计算，公告后下一交易日生效，避免将今天的分红套到过去所有价格。百分位=历史股息率≤当前股息率的有效交易日数÷总有效交易日数，值越高表示当前股息率在自身历史中越高。上市或有效分红历史不足5年时按实际可用交易日计算；不足60个有效交易日、披露日期缺失或历史价格过旧显示“待核实”。

历史行情通过AKShare腾讯日线按表内代码增量更新，分红明细复用本轮刚在线获取的数据。辅助表“股息率历史”保留各股票的样本区间、评估时股息率、历史值不高于当前值的天数及有效样本数；O列用公式计算两项计数之比。完整逐日年度股息、价格、历史股息率和来源限制保存在当日`dividend_percentiles.json`，不抽样近似。手动改变价格或分红后，O列显示“请更新”；运行`run.cmd`重新计算历史排名后恢复数值，避免显示过时百分位。这是基于当前可获得分红记录及公告日期的回溯估算，不具备历史方案修订的逐日快照；历史送转配股可能影响名义每股口径，相关提示保留在明细中。

新增列会随 `run.cmd` 自动更新，分红组成及接口来源保存在当日输出目录的 `rolling_dividends.json`。公式编辑及计算使用本机 Codex 自带的 Node/Artifact Tool；项目 `node_modules` 链接到该运行时。

P:S列依次为“60分位股息率（近5年）”“60分位对应股价（元）”“90分位股息率（近5年）”“90分位对应股价（元）”。沿用O列同一组历史样本，将历史股息率升序排列后取第`ceil(p×N)`项，不作线性插值；例如60分位表示至少60%的历史样本不高于该股息率。对应股价用公式`最新完整年度每股股息÷分位股息率`计算，分位为零时显示“不适用”。分红或历史数据不足时显示“待核实”；手动改变年度金额或所属年度后提示“请更新”。分位阈值、样本量和评估年度保留在“股息率历史”辅助表，逐日明细及对应股价也写入`dividend_percentiles.json`，每次正常更新会重新验证。

如需交互使用环境：

```powershell
conda activate .\.conda
```

## 重建环境

只请求工作簿中的股票，不下载全市场行情。A股行情直接使用腾讯 `https://qt.gtimg.cn/q=代码列表` 批量获取最新价格、涨跌幅和行情日期，行情流程不再尝试AKShare东财或雪球接口。港股行情及除息日使用Yahoo按代码查询；不以历史收盘价替代实时行情。A股分红明细继续使用 AKShare 1.19.1 的 `stock_fhps_detail_em(symbol=代码)`，异常时回退东方财富直连接口；两者共享上游，并非独立交叉验证。所有年度选择、去重和税前每股金额计算仍由本项目统一处理，不直接使用上游股息率字段。每次运行内复用刚获取的分红明细，并记录实际数据来源。巨潮、雪球和腾讯日线的对比测试脚本单独保留。

单次AKShare调用最多40秒，同类接口累计失败3次后本轮暂时停用。最新A/H股价格、汇率、分红公告及除息日每次在线检查，休市也检查；同一轮内刚获取的分红明细只复用一次请求结果。在线失败时明确提示并保留旧值，不把失败记为刷新成功。

历史缓存保存在 `data/.history_cache/`，可删除后自动重建：

- 首次获取近5年日线（另留14天边界余量）；没有新交易日时复用已完成的日线。新增日期时获取最近30天重叠区间并按日期合并，修正该区间已有价格；盘中不保存当天未完成的日线。
- 每7天复查最近30天，每30天全量复查，捕获历史修订。更早修订在下一次全量检查后反映；需要立即核对时可强制刷新。
- 历史股息率序列按分红明细（含金额、报告期、公告日期、进度）、日线、有效估值日、算法代码及参数计算SHA256指纹。任一变化即重建；最新价格变化时复用历史分布，但每轮重新计算当前股息率及百分位排名。
- 缓存包含来源、AKShare版本、校验摘要和检查日期；损坏或版本不匹配时重新下载，增量失败不覆盖已有有效文件。本次历史数据无法确认时百分位显示“待核实”。`.dy_cache.json`继续用于前次快照及失败时保留旧值，不用于跳过正常在线检查。

如需强制全量历史更新并重算，可在PowerShell中设置 `$env:DIVIDEND_HISTORY_FORCE_REFRESH='1'` 再运行，完成后执行 `Remove-Item Env:DIVIDEND_HISTORY_FORCE_REFRESH`。兼容旧参数 `DIVIDEND_FORCE_REFRESH=1`，同样绕过历史缓存；最新数据始终在线检查。

需要排查接口时，可开启请求级日志（包括接口地址、耗时、HTTP状态和异常堆栈）：

```powershell
$env:DIVIDEND_FORCE_REFRESH='1'
$env:DIVIDEND_DIAGNOSTICS_DIR=Join-Path (Get-Location) ('pictures\diagnostics_' + (Get-Date -Format 'yyyyMMdd_HHmmss'))
.\.conda\python.exe -X utf8 -u scripts\network_diagnostics.py
Remove-Item Env:DIVIDEND_FORCE_REFRESH, Env:DIVIDEND_DIAGNOSTICS_DIR
```

每个进程分别写入 `network-<进程号>.jsonl`，可区分上游请求失败与40秒子进程超时。诊断默认关闭，不改变正常更新逻辑。

```powershell
conda env create --prefix .\.conda -f environment.yml
```

程序位于 `scripts/`，回归测试位于 `tests/`。工作簿来自技能自带的示例，使用前请替换为自己的标的。初始化仅安装环境和检查文件，不抓取行情或更改示例数据。
