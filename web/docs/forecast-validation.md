# 手动预估股息率验证

验证日期：2026-11-07。当前功能已替换原自动盈利／公告模型；旧自动模型的公开数据样本和解析测试已随功能移除，不再作为当前功能的验证依据。

## 计算与接口

- 两种输入：年度每股金额，或股息率百分比。百分比保存时用后端当前有效股价折算，验证后续股价变动不重写已保存的每股股息。
- 手动值联动列表、目标价格、买卖网格；预估口径不回算历史分位，空值和清除不改用其他口径。
- 验证零值、缺失价格、港币／人民币换算、缺失汇率、跨年停用、ETF 排除、证券身份变更及非法／注入字段。
- 旧自动快照、公告承诺、盈利预测及旧人工支付率／利润模型不再影响结果，旧数据不清空。
- 旧自动刷新 POST 路由返回410，不请求公开预测来源、不写公开缓存；GET 兼容查看当前手动值。
- 通过真实 SQLite API 验证保存、清除及报价更新期间的并发人工编辑；多人版验证未登录401、他人标的404及用户间值隔离。

## 两版检查

单机版105项、多人版135项完整回归通过；两版类型、静态、生产构建和浏览器检查通过。单机隔离运行包、多人版 HTTP 账号运行、Wrangler dry-run及原生 workerd 检查通过。

单机版和多人版分别运行 ESLint、前后端 TypeScript、完整后端回归和 webpack 生产构建。单机隔离 HTTP 测试从无 node_modules 的临时运行包启动，验证 Node 内置 SQLite 与手动预估后端不再依赖 PDF／HTML 解析器。多人版另验证 Wrangler dry-run、账号 HTTP 运行及原生 workerd 的手动输入、报价锚定、币种换算和旧自动接口禁用。

Chromium 页面验证使用临时演示数据与临时账号，覆盖百分比／每股金额输入、保存与清除、报价变化、目标价、零值、港股币种、ETF 排除及390px手机布局；监控页面网络，确认不再产生预估自动查询请求。截图保存在各版 `.local/manual-forecast-ui-desktop.png`、`.local/manual-forecast-ui-mobile.png`。

所有自动检查仅使用内存、临时 SQLite／D1 或演示数据，不读取个人数据库、备份或初始快照，不发送真实邮件，不执行线上发布。本地预览完成检查后沿用原数据库重新启动，供用户自行验证。
