# 功能更新记录

## 2026-11-07：自定义每股股息与备注

- 自定义输入由百分比改为固定每股金额，支持人民币／港币和可选备注；ETF 对应每份分红。
- 股息率随报价更新，已保存金额保持不变；列表、排行、目标价和买卖网格采用同一口径。港股币种不同时只换算一次。
- 独立手动预估区域和选项已移除；旧百分比及有效人工金额经一次性转换保留，原字段和快照不删除。
- 单机103项、多人133项回归，以及两版浏览器和运行检查通过。详见 [使用说明](custom-dividends.md) 与 [验证记录](custom-dividends-validation.md)。

## 2026-11-06：预估年度股息率

- A 股、港股新增当前财年全年预估，自动检索分红承诺，并按盈利预测或利润 TTM 与普通支付率补充估算。
- 可选用预估口径联动目标价格、排行与网格；显示来源、核验进度、条件性下限与缺失原因。支持人工补充及恢复自动。
- 预估不回算历史分位，ETF 不适用。详见 [口径和使用说明](forecast.md)。

## 2026-11-03：Windows 与 Linux 一键启动

- 两版均支持 Windows `run.cmd`、Linux `run.sh` 自动安装依赖、webpack 构建并启动；后续复用未变化的依赖和页面。
- `setup.cmd` / `setup.sh` 只安装和构建，开发热更新仍使用 `npm run dev`。
- 增加端口与重复启动检查，失败后停止，保留已有配置和数据库；详见 [启动器说明](launcher.md)。

## 2026-11-03：统一 Windows 与 Linux 构建

- 默认构建、显式 `build:webpack` 入口和完整检查均使用相同 webpack 静态导出脚本，单机 Docker 沿用该入口。
- Windows 与 Linux 命令一致，各平台独立安装原生依赖；操作说明见 [跨平台构建](build.md)。

## 2026-11-03：补齐 QDII-ETF 搜索

- 修复 513530（港股通红利ETF华泰柏瑞）、513110 等被搜索规则漏掉的问题，支持数据源的 `QDII-ETF` 分类。
- 按境内上市的交易所识别：513530 保存为上海 ETF，使用人民币场内价格；仍排除 ETF 联接基金、LOF 和境外上市 ETF。

## 2026-11-03：分红日期说明与明细修正

- 股票年度明细明确所属财年，逐笔区分报告期、除息、登记、发放及公告日期。
- 最近已除息与下次除息分别显示，未来股票除息日仍能进入日历。
- 显示分红原始来源与数据更新时间；来源缺失的发放日期不再与除息日混用。
- 中谷物流的公告日期与跨年财年合计核验见 [日期口径说明](dividend-dates.md)。

## 2026-11-03：刷新更快，分红按日复用

- 刷新拆为价格和分红两个阶段，新价格先显示，分红查询继续进行。
- 分红按 UTC+8 自然日首次使用时查询，成功后当天缓存；预览与刷新复用结果。多人使用时同一标的共用公开分红，个人观察列表和设置仍独立。
- 查询失败保留已有数据，延后再试，不把缺失分红当作零。缓存跨服务重启保留。

## 2026-11-02：ETF 与观察流程补齐

- 支持沪深 ETF 的搜索添加、年度／滚动派息率、每份现金分红、逐次记录和已公告除息日期。
- ETF 历史分位跟随年度、滚动或自定义口径，展示当前百分位、60／90 分位及对应价格；ETF 不展示个股历史曲线。
- 首次使用提供招商银行与红利ETF华泰柏瑞两个默认观察标的，不给已有列表补入，删除后不重建。
- 长列表的股息查询能跨刷新续查；ETF 手工除息日能进入日历，与查询日期去重。

## 2026-11-01：观察指标与口径统一

- 列表增加日／周／月 BOLL 标签，详情支持查看通道和更新标签。
- 个股增加年度股息支付率；刷新补充年内涨跌基准，并显示基准日期、复权方式和缺失原因。
- 历史分位、曲线和分位对应价格跟随保存的年度、滚动或自定义口径；自定义回溯明确标为估算。
