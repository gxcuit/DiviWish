# 自定义每股股息检查记录

日期：2026-11-07。两版分别实现及检查，所有回归和浏览器检查只使用临时 SQLite／D1、演示数据及模拟邮件，不使用个人持仓测试。

## 算法与数据检查

| 场景 | 检查结果 |
| --- | --- |
| 每股1元，股价10元／20元／8元／12.5元 | 股息率分别为10%／5%／12.5%／8%，每股金额始终为1元 |
| 每股1元，目标股息率5% | 目标价20元，不随当前报价改变；买卖网格沿用同一每股分子 |
| 港股价格8 HKD，股息1 CNY，HKD/CNY=0.8 | 换算为1.25 HKD每股，股息率15.625%，目标5%时价格25 HKD |
| 港股价格8 HKD，股息1 HKD | 股息率12.5%，同币种不要求汇率 |
| 明确零金额 | 形成有效零股息率；缺失金额不使用年度或其他口径代替 |
| 股价缺失但每股金额已知 | 当前股息率缺失，目标价和网格仍可由每股金额计算 |
| 报价更新与并发备注／金额编辑 | 不重写人工金额、币种或备注；历史固定股息分子也不随报价重算 |
| 旧百分比、旧人工预估 | 一次性转换；原始参数与快照保留，缺少旧价时不以后续新价补算；重复执行不再锚定 |
| 账号与备注隔离 | 未登录401、他人标的404；两用户的旧输入分别转换且私有备注不混用 |

相同计算用于银行、矿业、石油及其他股票；示例不依赖任何公司的自动盈利或分红预测。ETF 使用每份分红同样计算。

## 执行范围

单机完整回归103项、多人完整回归133项通过。两版执行 ESLint、前后端 TypeScript、webpack生产构建及本地运行检查。多人增加 Wrangler dry-run及原生 workerd 验证；不调整生产配置兼容日期，不部署线上或操作远端数据库。

浏览器检查覆盖金额和备注保存、重新打开后保留、报价10→20使股息率10%→5%、目标价／网格固定、港股币种换算、零值、ETF份额、740×615和390px布局，以及独立预估区域／选项／自动请求均已移除。演示截图位于各版 `.local/custom-dividend-ui-desktop.png`、`.local/custom-dividend-ui-740.png`、`.local/custom-dividend-ui-mobile.png`。

本地用户验证入口继续使用3000（单机）和3001（多人），分别沿用本版原有数据库。备份和旧快照不清理。规则和接口见 [说明](custom-dividends.md)。
