# 手动预估年度股息率

从2026-11-07起，预估股息率改为用户手动维护。自动盈利预测、TTM／支付率模型、公告检索和解析、自动刷新进度、利润股本核对及剩余分红预测界面均已移除。普通行情与已披露年度／滚动分红刷新继续保留。

## 使用

打开 A 股或港股详情，在“预估股息率（手动）”选择填写方式：

- 预估股息率（%）：按保存时的有效股价折算并保存年度每股股息，币种采用股价币种。之后更新报价只会改变显示股息率，不重新锚定保存的每股股息。没有有效价格时须先保存价格，或改用每股金额输入。
- 年度每股股息：直接保存人民币或港币金额，股息率为该金额除以当前股价；币种不同时用已有人民币／港币汇率换算，缺少汇率保持缺失。

可保存财年与备注，只使用当前财年人工值。跨财年停止使用旧值，须重新填写；清除后保持空缺，不恢复自动模型。明确预估零分红可填0。全年金额包含同财年中期分红，不要重复叠加，不代表今天买入后未来十二个月可领取的金额。

在口径选择中保存“手动预估年度股息率”后，联动列表、排行、目标价格及买卖网格。缺失时不偷换成年度、滚动或自定义口径。预估没有各历史时点预测记录，不计算历史分位或分位对应价格。ETF 不适用。

## 接口与数据保留

通过 `PATCH /api/stocks/:id` 保存 `forecast_manual`，输入结构如下。`value` 为每股币种金额，或股息率小数；界面百分比会先除以100。

```json
{
  "forecast_manual": {
    "year": 2026,
    "kind": "yield",
    "value": 0.05,
    "currency": "CNY",
    "note": "人工判断依据"
  }
}
```

`kind` 为 `yield` 或 `per_share`；后端生成 `dividend`、`reference_price` 和 `updated_at`，客户端不自行指定这些计算字段。清除传 `forecast_manual: null`。股票响应中的 `forecast` 只计算人工值与报价的比值，不读取旧自动快照。

`GET /api/stocks/:id/forecast` 兼容读取手动结果；原 `POST /api/stocks/:id/forecast` 返回410并提示人工填写，不发起外部请求、不写缓存。多人版先执行会话和股票所有权检查，跨用户读写保持404。

保留既有数据库、自动快照、缓存表及历史迁移，避免破坏个人数据；它们不再参与计算。旧的承诺／支付率／利润股本人工参数也不再运行，原始记录保留到用户明确保存或清除，界面提示重新填写。身份变更仍清除该标的关联参数。无需清空或重建数据库，不读取另一版本个人数据库。

自动预估专用源码、公共样本检查脚本及 PDF／HTML 解析依赖已移除，单机运行镜像不再需要这些 node_modules。两版分别保留各自数据库与认证模型。

验证范围见 [验证记录](forecast-validation.md)。
