# 预估年度股息率

预估的是北京时间当前财年全年现金股息，包含同财年中期分红，不代表今天买入后未来十二个月能领取的金额。首版支持十二月年结的 A 股和港股，ETF 不适用。年度、滚动、自定义口径继续保留；已有标的不会自动改用预估口径。

## 使用

打开个股详情，在“预估年度股息率”查看每股金额、公式、盈利口径、支付率参考年份、来源及获取时间。首次进入列表或刷新行情与股息后，页面独立获取预估资料。公告每次只解析少量文件；首轮自动执行有限批次，剩余公告可点击“继续核实公告”续查，游标跨请求保存。“重新检索来源”会重新查询当日公开数据，已下载的官方公告文本继续复用。

在股息率选择中选“预估年度股息率”，保存后用于列表、排行、目标价格和买卖网格。目标价格为预估每股股息除以目标股息率。缺失数据时显示空值及原因，不暗中改用年度或滚动股息率。预估口径不展示历史分位、曲线及分位对应价格，因为没有各历史时点的预测快照。

“人工补充分红承诺／参考支付率”可输入全年每股金额、全年总额或利润分配比例，以及币种、适用财年、条件和公告链接。总额须填写公告适用的参与分红股数；比例须选择归母或普通股股东利润分母。人工承诺优先，人工参考支付率在没有可用承诺时使用。清除后恢复自动。人工设置属于当前用户／本机，不写入公共缓存。

## 计算顺序

1. 目标财年完整普通分红方案：同财年各期普通现金股息加总，明确特别股息另列。年末方案与中期方案各计一次；仅有中期方案时不视为全年方案。明确不分红可形成有效零值。
2. 有效公告承诺：每股金额直接使用；总额除以公告适用股数；利润比例乘以匹配口径盈利。“不低于”标为条件性下限，适用条件仍需成立。
3. 无可用承诺：核对后的预计普通股利润除以参与股数，乘以历史普通现金支付率中位数；仅满足稳定股数等条件时采用基本 EPS 近似。回看最近五个完整财年，取其中最近三个有效年份，不足三年使用已有有效年份。每年需有完整年度记录、正收益、同币种股息。明确特别股息不纳入普通分红，金额无法拆分的年份跳过；普通支付率超过100%的年份按异常跳过并注明。

盈利依次使用目标财年已披露全年实际盈利、目标财年机构盈利预测、最新完整利润 TTM。TTM 为上年全年加本年累计减上年同期累计，不把半年利润简单乘二。直接加减每股收益须有稳定股本；总额利润与每股口径分别匹配。归母净利润比例不直接等同于普通股每股收益，存在优先股扣减等明显差异时不自动套用。

港股从原始利润表核实收益币种，不采用行情页的交易币种标签；经济通的“分”“港仙”“美仙”分别按原币单位除以100。股息与股价币种不同，仅使用明确的汇率换算。历史支付率要求股息和收益原币一致，不用今天汇率强行配平历史年份。

盈利非正、股本或币种不能匹配、历史不足均显示原因。已公告普通中期分红高于模型全年结果时暂停估算，提示核实，不能额外把中期分红再加到全年模型结果中。跨财年停止使用旧年度快照和人工参数。

## 来源与公告识别边界

- A 股财务报表与机构预测来自东方财富。预测需匹配目标年份与预测标识，并有机构覆盖；来源提供近六个月覆盖但没有单独预测日期时，界面明确获取日期不等于研报日期。
- 港股财务报表来自东方财富原始报表；盈利预测来自经济通，按最近183日、同财年的机构记录去重后取均值，并显示机构数量与最新记录日期。
- A 股公告从巨潮资讯检索，港股从披露易检索，首轮覆盖最近五年。列表分页与 PDF 解析均保存续查位置。
- 公告自动采用须从官方正文识别证券代码、生效／批准状态、适用年份、单年现金金额或比例和利润分母。保留链接、日期、页码及依据摘录。含回购、多年累计约束、未批准或复杂条件的条款保守地标记待核实。
- 承诺检索尚未完成时，先展示明确标注的盈利模型；全部核实后才自动采用承诺。多份条款冲突时使用历史模型并提示人工核实；发现较新的变更／撤销公告但尚未核实其条款时，停用旧承诺。
- 只处理可提取文字的公告，不使用付费模型或 OCR。单份公告限5 MiB、80页，文本限40万字符；超限、扫描件及不能可靠识别的条款可人工补充。
- “检索失败”“未发现可用承诺”“待核实”“仍有剩余公告”分别展示，均不等于公司没有分红承诺。现阶段规则不能保证覆盖所有公司或复杂条款。

## 开发接口与存储

`yield_basis` 增加 `forecast`。股票响应增加 `forecast` 对象，包括 `year`、`status`、`dividend`、`currency`、`yield`、`basis`、`earnings_basis`、输入值、参考年份、公式、来源、公告核验状态、更新时间和 `stale`。未完成公告数量包含待解析文件及检索分页。

- `GET /api/stocks/:id/forecast`：读取当前结果，兼容返回个股详情。
- `POST /api/stocks/:id/forecast`，JSON `{}`：获取当日公开数据或继续公告核验。
- `POST /api/stocks/:id/forecast?refresh=1`：重新检索公开来源。
- `PATCH /api/stocks/:id`：保存或清除 `forecast_manual`。人工对象含 `year`、`payout_ratio`、`commitment` 及可选 `reconciliation`；清除传 `null`。金额使用币种基本单位，比例使用小数，总额股数使用股。

自动原始快照保存在股票文档内，API不暴露整份原始快照。公共缓存只从传入证券身份的公开适配器生成，按证券、财年和 UTC+8 日期保存，通过数据库租约避免并发重复请求。官方文本按公告标识缓存。上游错误不填零，保留旧快照／可用的旧分项并标记；刷新期间人工参数或身份改变时拒绝覆盖旧计算。

单机迁移为 `0003_forecasts.sql`，多人迁移为 `0006_forecasts.sql`，分别建立公开预估与公告文本缓存表，不迁移或读取另一版本个人数据库。多人版所有股票操作仍由会话派生用户身份。

## 检查

从 `web/` 运行 `npm run check`。公开数据源只读抽查使用 `node scripts/check-forecast-sources.mjs`，不打开个人数据库。该脚本使用虚拟股价，只验证取数和计算链路，输出不是实时投资参考；个别来源不可用时应检查显示的具体原因。

单机 Docker 会从已安装的锁定版本提取 PDF／HTML 解析器及其传递依赖，保留 npm 的嵌套版本结构，不把前端构建工具带入运行镜像。隔离运行检查同时验证实际 PDF 文本解析；多人版的原生 workerd 检查覆盖解析器、D1 预估与公告文本缓存及人工参数隔离。

## 利润与股本核对、分红进度（2026-11-06）

详情新增“利润与股本核对”和“分红进度与剩余预测”。全年模型、已实施普通分红、已批准待实施、预案、条件性指引、特别股息分别展示。金额无法确定时显示待核实；分红记录保留原币、归属报告期、来源、除息日和支付日。实施方案已公布但尚未除息／支付时归入待实施，已除息不等于当前持有人已到账。同一报告期的新记录替换旧记录，等日冲突保留待核实。

剩余普通分红预测＝全年普通分红模型－同财年已公布普通分红（含已实施、已批准及预案）。条件性指引与特别股息另列，不能作为已确定普通分红扣减；多个条件指引不强行加总。全年下限推算的剩余仍标为条件性下限。全年模型缺失或低于已公布金额时，剩余保持缺失，已公布各项继续展示；不会将负值截成零伪装正常结果。

普通股利润＝归母利润－同期间权益工具损益调整。基本 EPS 已反映普通股收益调整，使用 EPS 不重复扣减。加权平均普通股数用于基本 EPS 的利润分母；预计参与分红股数用于总额转每股，需排除没有参与权的库存股。禁止用“EPS × 期末股本”反推真实归母利润，也不把资产负债表的货币股本当成股数，不把优先股／永续债／其他权益工具余额当作全年损益扣减。

A 股适配器补查同证券、同报告期、截至查询日已披露的银行／通用资产负债表，对所有行业应用相同规则。存在其他权益工具、库存股、股本变动或未核实资料时，不能以普通股利润近似通过核对。资料完整时历史参考支付率优先使用各期普通现金总额之和除以同年普通股利润；只有股数稳定且没有库存股等冲突时，才使用明确标为近似的 DPS／基本 EPS。TTM 权益扣减也必须按“上年全年＋本年累计－上年同期累计”匹配，不能机械沿用上年扣减。港股当前原始报表尚未自动核实权益工具／参与股数，盈利模型需要人工核对；已公布方案或每股／总额承诺仍可单独形成结果。

人工入口增加 `forecast_manual.reconciliation`：币种、预计全年归母利润、全年权益工具损益扣减、预测基本 EPS 对应加权平均普通股数、预计参与分红股数、依据链接和假设。可填写“全年归母利润＋全年扣减”，或“预测基本 EPS 对应的加权股数”；利润用元，股数用股，确认全年没有扣减须明确填0。人工全年利润显示为人工假设；该输入不属于机构一致预测。参考支付率按普通股利润口径填写。所有人工字段继续只属于当前用户／本机，刷新不覆盖期间修改，跨财年停用。自动公开缓存使用 v2 键，旧记录没有状态或核对资料时要求刷新，不推断为已实施或零扣减。

只读实测：`node scripts/check-forecast-reconciliation.mjs`；加 `--capture` 可更新仅含公开接口字段的回归样本，绝不读取个人数据库。样本使用虚拟股价10元，只检查数据和计算链路。2026-11-06 对齐鲁银行、招商银行、紫金矿业、中国石油验证：前三者的权益工具／股本依据需补充，保留分红进度并暂停不可靠全年模型；紫金矿业0.42元已实施与不低于0.38元的条件指引分开；中国石油0.26元中期分红从普通全年模型中扣除一次。上述数值只代表抓取时接口记录，不构成对公告条款的法律确认。
