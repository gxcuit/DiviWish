# 自定义每股股息

在个股详情的“选用股息率”中选择“自定义每股股息”，填写金额、币种及可选备注，再保存。ETF 对应“自定义每份分红”。独立的手动预估区域和选项已移除，自动预估模型也不会恢复。

## 计算

- 保存的是固定每股金额，不是百分比。例如每股股息1元，股价10元时股息率10%；股价20元时股息率5%。报价刷新不修改该1元金额。
- 当前股息率＝每股金额（换算至股价币种）÷当前股价。
- 目标价格、买卖网格价格＝同一个已保存每股金额（换算至股价币种）÷目标股息率。例如每股1元、目标5%，目标价为20元，与当前股价无关。
- 金额为0与缺失不同：0形成有效零股息率，留空不改用其他口径。缺少股价时不能计算当前股息率，但金额已知仍能计算目标价格。
- 港股报价为HKD，可输入CNY或HKD股息。汇率为每港币对应人民币，例如1元人民币股息、股价8港元、汇率0.8，股息率为1÷0.8÷8＝15.625%；不会再次换算。同币种不要求汇率，不同币种且汇率缺失则保持缺失。

列表、排行、颜色、目标价和网格采用同一套金额和股息率。自定义历史曲线为“固定股息金额÷历史收盘价”的估算回溯，并非历史实际分红；当前股价变化不改写历史曲线的股息分子。备注属于当前用户／本机，不进入公开数据缓存。

## 接口

`PATCH /api/stocks/:id` 可保存以下字段：

```json
{
  "yield_basis": "custom",
  "custom_dividend": 1.2,
  "custom_dividend_currency": "CNY",
  "custom_dividend_note": "全年普通股息假设及依据"
}
```

金额用币种基本单位；币种支持CNY、HKD；备注最多2000字。缺省币种采用股票报价币种。新请求不再接受 `custom_yield`、`forecast_manual` 或预估口径。旧 `/forecast` 路由在身份与所有权检查后返回410。

## 原有数据

单机迁移 `0004_custom_dividends_legacy.sql`；多人迁移 `0007_custom_dividends_legacy.sql`（兼容表）及 `0008_custom_dividends_accounts.sql`（账号表）。本地启动按各自迁移执行，线上迁移不在本次任务执行。

旧自定义百分比按升级时已经保存的股价一次性折算为每股金额，保持升级时的股息率。之后无论报价如何变化，均不再折算。缺少当时有效股价则保持金额缺失并提示核对，不能把以后新报价当成旧保存价格。有效零比例可转为零金额。

当前财年已保存的手动预估金额、币种和备注转入自定义，旧口径变为custom。非当前财年或资料不完整时保持缺失，不能用另一个旧百分比代替。原始百分比、预估参数、自动快照及缓存仍留在数据库中归档，计算与界面不再读取。已选年度／滚动口径保持原选择，证券身份变更清除关联自定义参数。自定义金额不再自动按财年失效，由用户维护。

验证结果见 [检查记录](custom-dividends-validation.md)。
